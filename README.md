# Jeu de Morpion -c
Mini jeu morpion en C

## Description
Jeu de morpion pour 2 joueurs dans le terminal.
Le premier qui aligne 3 symboles gagne.

## Comment compiler
Methode 01: Ouvrir main.c avec Code::Blocks puis cliquer sur Build and Run (touche F9)
Methode 02:gcc main.c -o morpion

## Comment jouer
./morpion
Ensuite entrer ligne et colonne (1 à 3)
Exemple: 2 2 pour jouer au centre

## Fonctionnalités
- Affichage grille
- Vérification (ligne, colonne, diagonale)
- Match nul
- 2 joueurs X et O
